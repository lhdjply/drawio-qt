# 形状库

drawio-qt 的形状库全部由本地代码/资源渲染，**不依赖 Web 引擎**。入口是
`ShapeCatalog`：它同时管理内置矢量形状与 draw.io 的图片库资源，向形状面板、
插入菜单和画布提供统一的形状定义。

## 2. 使用方式

1. 左侧“形状”面板：
   - 顶部搜索框按名称/库名搜索（如“电容”“Azure”“VPC”）；
   - 下拉框选择库或“全部内置形状”；
   - 双击插入到视图中心，或直接拖到画布。
2. “插入 → 形状库…”：勾选需要显示的库（与 draw.io 的库选择对话框一致），
   选择结果保存在 `QSettings`。
3. 插入图片库形状时，生成的单元格样式与 draw.io 一致：
   `shape=image;image=img/lib/azure2/compute/Azure_Linux.svg;...`，因此
   保存的 `.drawio` 文件在 draw.io 中打开时能正确显示；反之，draw.io 文件中的
   `img/...` 图片引用也会由本程序解析渲染。

## 3. 如何新增形状

### 3.1 矢量形状

1. 在 `ShapeRegistry::toolboxShapes()` 中 `add(key, name, style, size, category)`；
2. 若需要自定义轮廓，在 `ShapeRegistry::pathForStyle()` 中按 `shape` 值添加分支；
3. 需要内部装饰（文字/刻度/折线）时，在 `ShapeRenderer::paint()` 的装饰分支中绘制；
4. 在 `ShapeCatalog::builtinCategoryName()` 与 `loadBuiltins()` 的顺序表中补充类别名。

### 3.2 图片库

把图标放入 `resources/assets/drawio/img/<库名>/...`（SVG 或 PNG）。`ShapeCatalog`
启动时会扫描目录、读取 SVG 尺寸、按文件名生成名称并自动分类；无需编写 C++ 代码。
构建时通过 `file(GLOB_RECURSE ...)` 打包进资源。

## 4. 尚未移植的库

draw.io Web 版有 40+ 形状库，其中不少由数千个 JS 绘图函数组成（每个形状是一个
`mxShape` 子类，用 Canvas API 绘制），无法直接照搬为声明式数据。以下库目前仍
缺失或仅有简化实现，可按需继续移植：

- AWS（3D/4/4b/Retired）、Google Cloud、Cisco（19/Safe）、Kubernetes 完整图标集
- ArchiMate 3、SysML 完整版、UML 2.5、Infographic 完整版、Lean Mapping
- Floorplan 完整版、Mockup 完整版、iOS/Android 完整 UI 组件
- Salesforce、Sitemap、Cabinets、GMDL、EIP 完整版、Electrical 完整版
- Emoji/Mockup 等图片或表情库

继续扩展的建议：

- 优先移植与业务相关的库（如所在团队的 AWS/GCP 架构图）；
- 图片类库可直接补充到 `resources/assets/drawio/img/`，零代码接入；
- 复杂矢量库可按 `ShapeRegistry` 与 `ShapeRenderer` 的模式分批实现，
  每个形状保持可导出、可打印、可撤销。
