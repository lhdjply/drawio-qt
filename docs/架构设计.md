# 架构设计

## 1. 总览

```
┌──────────────────────────────────────────────────────────────────┐
│                           ui（Qt Widgets）                        │
│  MainWindow   DiagramView   ShapeToolbox   FormatPanel   Dialogs   │
│       │            │             │              │                   │
│       └────────────┴─────────────┴──────────────┘                   │
│                          │ 编辑操作 / 快照撤销                       │
├──────────────────────────┼───────────────────────────────────────────┤
│                         app（应用服务）                             │
│      Args（命令行）   CliExport（批处理）   AppSettings（QSettings） │
├──────────────────────────┼───────────────────────────────────────────┤
│                          │ 页面 / 文档                              │
│  io                     core（无 UI 依赖，可单测）                   │
│  Exporter  ───────────► Document ── Page ── Cell ── Style           │
│  HtmlExport             MxFileIO  Compression  FileMeta              │
├──────────────────────────┼───────────────────────────────────────────┤
│                          │ Page 只读                               │
│                       render（纯绘制）                               │
│   DiagramRenderer ─ ShapeRenderer ─ EdgeRouter ─ EdgeRenderer        │
└──────────────────────────────────────────────────────────────────┘
```

依赖方向严格单向：`ui → app → io → render → core`，`render` 只读访问 `core`，
`core` 不包含任何 `QtWidgets`/`QtGui` 依赖（仅 `QColor`、`QRectF` 等值类型），
因此命令行导出与单元测试可以完全脱离窗口运行。

## 2. 核心数据模型

### 2.1 `Cell`

- `Cell::Kind::{Vertex, Edge}`
- 顶点：`geometry`（相对父元素）、`rotation`
- 边：`sourceId/targetId`、自由端点 `sourcePoint/targetPoint`、控制点 `waypoints`
- 公共：`id`、`value`、`style`、`parentId`、`visible`、`parent/children`
- 关键方法：`absoluteRect()`、`absolutePosition()`、`mapToAbsolute()`、`isContainer()`

几何坐标约定：**页面坐标 = 图层坐标**；分组子元素坐标相对于分组左上角。
坐标换算只在 `Cell::absolutePosition()` 一处递归完成，渲染、命中测试、
导出都基于绝对坐标，避免重复换算。

### 2.2 `Page`

- `name`、`id`、`settings`（网格、页面尺寸、pageScale、阴影）
- `layers`（`Layer{id,name,visible,locked}`）
- 单元格存储：`std::vector<std::unique_ptr<Cell>>` + `QVector<Cell*>`（z-order）+
  `QHash<QString, Cell*>`（O(1) 查找）
- 操作：`addVertex`、`addEdge`、`removeCell`（级联子元素与关联边）、`moveCell`（z-order）、
  `contentBounds`、`pageRect`、`newId`

### 2.3 `Document`

- 多页面容器，当前页索引、文件路径、修改标记、压缩开关、只读状态
- `load()` 自动识别 `.drawio/.xml` 与内嵌图数据的 PNG/PDF/SVG
- `pageXml()/restorePageXml()` 为撤销和剪贴板提供页面级序列化

## 3. 渲染管线

```
paintEvent
  ├─ 背景色（深/浅）
  ├─ QPainter.scale(zoom); translate(-pan)      // 视图变换
  └─ DiagramRenderer::paint(page, options)
        ├─ 页面阴影 + 白色纸张
        ├─ 网格（页面范围或内容包围盒）
        ├─ 顶点：按 depth 排序，父容器先画
        │     └─ ShapeRenderer::paint
        │           ├─ 旋转/透明度/阴影
        │           ├─ ShapeRegistry::pathFor 生成路径
        │           ├─ 渐变 / 纯色填充 + 描边
        │           ├─ 形状装饰（圆柱顶盖、便签折角、泳道标题线…）
        │           └─ LabelPainter（QTextDocument 或 QTextLayout）
        └─ 边：EdgeRenderer::paint
              ├─ EdgeRouter::route → 折线点集
              ├─ 圆角路径
              ├─ 起止箭头
              └─ 连线标签（按文字宽度绘制背景）
```

同一个 `DiagramRenderer` 同时服务：

- 画布（`DiagramView::paintEvent`，附加选择框/控制点覆盖层）；
- PNG/JPEG 导出（`QImage` + `QPainter`）；
- SVG 导出（`QSvgGenerator`）；
- PDF 导出（`QPdfWriter`）；
- 打印/打印预览（`QPrinter`）。

因此“所见即所得”在五个出口上天然一致。

## 4. 连线路由

`EdgeRouter::route` 的步骤：

1. **确定端点**：有 `exitX/exitY`、`entryX/entryY` 时按比例取形状边框点；
   否则从源中心向目标中心发射射线，与形状路径（`pathFor().toFillPolygon()`）
   求交，得到边框交点与出射方向；
2. **选择路由**：`edgeStyle` 为空或 `orthogonalEdgeStyle/elbowEdgeStyle/entityRelationEdgeStyle`
   走曼哈顿路由；其他（`segmentEdgeStyle`）走直线；
3. **正交构造**：
   - 无控制点：根据两端出射方向选择“水平-水平取中轴 / 垂直-垂直取中轴 / L 形”；
   - 有控制点：沿控制点交替水平/垂直推进，最后按目标入射方向补齐肘部；
4. **简化**：删除重复点与同向共线点（保留反向折返点，因为它可能是用户控制点）；
5. **绘制**：圆角用 `quadTo` 实现；箭头按最后一段方向绘制。

复杂度 O(形状边数 + 控制点数)，不依赖布局求解器，交互实时。

## 5. 撤销/重做

采用**页面快照**而非细粒度命令：

- 每次编辑前后各序列化一次 `mxGraphModel`（未压缩，通常几 KB～几百 KB）；
- `PageSnapshotCommand` 保存 `before/after` XML 与选择集；
- `QUndoStack` 上限 200 步；
- 拖拽/缩放：鼠标按下时记录快照，释放时比较差异，有变化才入栈；
- 连续属性修改（颜色、字号等）各自成为一步，符合直觉；
- 第一次 `push` 时跳过 `redo()`（编辑已应用），避免重复解析。

优点：实现简单、对任意编辑操作天然正确；缺点：超大文档的内存开销较高。
如需优化，可在 `Document` 上增加分页 diff 或命令化编辑。

## 6. 多页面与图层

- 页面即 `<diagram>`，由 `MainWindow` 底部 `QTabBar` 驱动；
- 每个页面独立维护 `Page::Settings` 与撤销栈共享（撤销命令记录页面索引）；
- 图层用 `Layer` 表示，读写在 `MxFileIO` 中完成；渲染时按 `Layer.visible` 过滤；
  当前版本未提供图层管理 UI，但数据不会丢失。

## 7. 文件读写流程

### 打开

```
openFile(path)
  ├─ Document::load
  │    ├─ 读字节 → FileMeta::detect
  │    ├─ PNG/PDF/SVG → 提取内嵌 XML（必要时解压）
  │    ├─ 文本 → MxFileIO::documentFromXml
  │    │     ├─ QDomDocument 解析
  │    │     ├─ 每个 <diagram>：嵌套 XML 或 base64 解压
  │    │     └─ 图层 / 单元格 / 几何 / 控制点
  │    └─ 重置修改标记
  ├─ view.refreshFromDocument + fitToWindow
  ├─ 最近文件 / 窗口标题 / 页面标签
  ├─ 启动文件监视
  └─ 检查自动保存草稿
```

### 保存

```
saveTo(path)
  ├─ Document::save（QSaveFile 原子写）
  │     ├─ .xml → 未压缩；其他 → 压缩页面
  │     └─ 更新路径与修改标记
  ├─ 最近文件、最后目录
  ├─ 删除草稿、重启文件监视
  └─ 状态栏提示
```

## 8. 导出流程

```
Exporter::exportDocument(document, options)
  ├─ png/jpg → exportImage：计算包围盒/缩放 → QImage → 可选 pHYs 与 zTXt
  ├─ svg     → exportSvg：QSvgGenerator → 可选 content 属性
  ├─ pdf     → exportPdf：QPdfWriter（每页独立尺寸）→ 可选 /Subject 增量更新
  ├─ xml     → mxfile 容器（可压缩）
  └─ html    → HtmlExport：data-mxgraph + viewer-static.min.js
```

包围盒来自 `DiagramRenderer::contentBounds`（含描边、阴影、箭头），
`--border` 在其外扩展，`--width/--height` 反算缩放，`--size page` 改用页面矩形。

## 9. 交互状态机（DiagramView）

```
Idle ──鼠标按下──► Move | Resize | Marquee | Pan | Connect
  ▲                    │
  └──── mouseRelease ──┘（比较快照，必要时 push undo）
```

- 命中顺序：选择控制点 → 悬停形状的连接点 → 边（距离阈值）→ 顶点（逆 z-order）；
- 双击：顶点/边进入文本编辑；空白处创建矩形并编辑；
- 键盘：Delete、方向键、Enter/F2、Ctrl+C/X/V/D/A、Space（平移）、Esc；
- 拖放：形状面板 MIME `application/x-drawio-shape`；外部文件 URL 转交 `MainWindow`。

## 10. 性能考虑

- 单线程绘制，适合数百到数千单元格；`paintEvent` 依赖 Qt 的裁剪与抗锯齿；
- 顶点按深度排序后绘制，避免重复遍历；
- 连接线路由每次绘制时计算（未缓存），对大型图可增加路径缓存与脏标记；
- 撤销快照会随文档增大，可通过 `QUndoStack::setUndoLimit` 调整。
