# 构建、运行与打包

## 1. 环境要求

| 组件 | 版本 | 备注 |
| --- | --- | --- |
| CMake | ≥ 3.21 | 使用 `qt_add_resources` |
| 编译器 | C++20 | GCC 11+、Clang 14+、MSVC 2022 |
| Qt | ≥ 6.5 | 模块：Core、Gui、Widgets、Svg、PrintSupport、Xml、Test |
| zlib | ≥ 1.2 | 压缩页面、PNG、PDF 处理 |

本项目**不需要** Qt WebEngine、Node.js、Electron 或任何浏览器运行时。

## 2. Linux（Ubuntu / Debian / deepin / Fedora）

### Debian 系

```bash
sudo apt update
sudo apt install build-essential cmake zlib1g-dev \
    qt6-base-dev qt6-svg-dev qt6-tools-dev libqt6printsupport6
```

> 如果 `qt6-base-dev` 未附带 PrintSupport，请确认安装 `libqt6printsupport6`
> 或发行版对应的 `qt6-base-private-dev` 包。

### Fedora

```bash
sudo dnf install gcc-c++ cmake zlib-devel \
    qt6-qtbase-devel qt6-qtsvg-devel qt6-qttools-devel
```

### 构建

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j"$(nproc)"
./build/drawio-qt
```

### 无界面环境（服务器 / CI）

导出模式会自动选择 `offscreen` 平台：

```bash
unset DISPLAY
./build/drawio-qt -x -f png -o out.png input.drawio
```

也可以显式指定：

```bash
QT_QPA_PLATFORM=offscreen ./build/drawio-qt -x -f svg -o out.svg input.drawio
```

## 3. Windows

1. 使用 Qt 在线安装器安装 Qt 6.8（MSVC 2022 64-bit），勾选
   `Qt 6.x.x → MSVC 2022 64-bit`、`Qt Svg`、`Qt Tools`；
2. 安装 CMake 与 Visual Studio 2022（含“使用 C++ 的桌面开发”）；
3. 配置与构建：

```bat
cmake -S . -B build -G "Visual Studio 17 2022" -A x64 ^
      -DCMAKE_PREFIX_PATH=C:\Qt\6.8.0\msvc2022_64
cmake --build build --config Release
build\Release\drawio-qt.exe
```

部署运行时：

```bat
windeployqt --release --no-translations build\Release\drawio-qt.exe
```

`WIN32_EXECUTABLE` 已设置，发布版不会弹出控制台窗口；命令行导出时若需查看日志，
可在 `main.cpp` 中去掉该属性，或重定向输出。

## 4. macOS

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release \
      -DCMAKE_PREFIX_PATH="$HOME/Qt/6.8.0/macos"
cmake --build build -j"$(sysctl -n hw.ncpu)"
open build/drawio-qt.app
```

打包：

```bash
macdeployqt build/drawio-qt.app -dmg
```

`MACOSX_BUNDLE` 已在 CMake 中配置；图标可通过 `MACOSX_BUNDLE_ICON_FILE`
替换为 `.icns`。

## 5. 安装

```bash
sudo cmake --install build --prefix /usr/local
```

安装内容：

- `bin/drawio-qt`
- `share/applications/io.github.drawioqt.desktop`
- `share/icons/hicolor/256x256/apps/drawio-qt.png`
- `share/drawio-qt/examples/*.drawio`

桌面菜单会在下次会话刷新后出现（或执行 `update-desktop-database`）。

## 6. 打包建议

| 平台 | 工具 | 说明 |
| --- | --- | --- |
| Linux | `linuxdeploy` + `linuxdeploy-plugin-qt` | 生成 AppImage，Qt 插件需一并打包 |
| Windows | `windeployqt` + Inno Setup / WiX | MSI 可参考上游的 `electron-builder-*.json` 结构 |
| macOS | `macdeployqt` | 生成 `.app`/`.dmg` |

Qt 资源（图标、示例）已编译进二进制（`qt_add_resources`），无需额外拷贝。

## 7. 测试

```bash
cmake -S . -B build -DDRAWIO_QT_BUILD_TESTS=ON
cmake --build build -j"$(nproc)"
QT_QPA_PLATFORM=offscreen ctest --test-dir build --output-on-failure
```

| 测试 | 覆盖内容 |
| --- | --- |
| `tst_args` | 命令行解析、组合短参数、默认值、帮助文本 |
| `tst_model` | 单元格增删、级联删除、分组坐标、z-order、页面管理 |
| `tst_mxfile` | 压缩/未压缩 XML 往返、图层、百分号编码 |
| `tst_filemeta` | PNG/SVG/PDF 内嵌 XML 读写、签名识别 |
| `tst_router` | 正交路由、控制点、约束、椭圆连接点 |
| `tst_export` | 六种导出格式、透明背景、宽度适配、PDF 多页 |
| `tst_ui_smoke` | 离屏窗口渲染、选择/撤销、原位编辑、保存重开、剪贴板 |

`tst_ui_smoke` 会在构建目录生成 `ui-smoke.png`，可用于人工检查界面。

## 8. 常见问题

**Q：启动提示 `Could not load the Qt platform plugin "xcb"`**
安装 `libxcb-cursor0`、`libxkbcommon-x11-0` 等 X11 依赖，或使用
`QT_QPA_PLATFORM=wayland` / `offscreen`。

**Q：中文显示为方框**
安装中文字体（`fonts-noto-cjk` / `fonts-wqy-zenhei`），Qt 会通过 fontconfig 自动选择。

**Q：导出 PDF 中文缺失**
`QPdfWriter` 依赖系统字体嵌入，请确保中文字体已安装；导出的 PDF 会嵌入所用字形。

**Q：命令行导出没有输出**
检查是否设置了 `QT_QPA_PLATFORM=offscreen`；查看退出码（0 成功，1 失败）与 stderr。

**Q：打开 draw.io 文件后形状样式不对**
原生渲染器支持常用样式子集，未知 `shape=` 会退化为矩形；可在
`ShapeRegistry::pathForStyle` 中补充。

**Q：撤销栈占用内存过大**
在 `DiagramView` 构造函数中调小 `m_undoStack->setUndoLimit(...)`（默认 200）。

## 9. 开发建议

- 新的 UI 逻辑不要写进 `core/`，保持核心层可测试；
- 绘制逻辑一律放进 `render/`，确保导出与画布一致；
- 修改文件格式相关代码后，运行 `tst_mxfile` 与 `tst_export`；
- 提交前执行完整构建（含 `-Wall -Wextra -Wpedantic`）。
